ptserver
=======

A server application for testing / documenting / debugging the old Paltalk
protocol and client.

This is still incomplete but largely functional.

Just build with the ``Makefile`` and enjoy.

Dependencies
------------

- sqlite3

Getting Started
---------------

See the [wiki](https://github.com/thentenaar/ptserver/wiki) for information
on various client versions, and other odds and ends you'll need to get
the most out of ``ptserver``.
